# List of common functional acronyms

Listed alphabetically

| Acronym    | Meaning                                                                             | Additional info                                                                                                                                                                                                                                              |
|------------|-------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AC         | Alternate Current                                                                   |                                                                                                                                                                                                                                                              |
| BCI        | Base case improvement                                                               | A step of the merging process, described [here](/doc/step_details/bci.md)                                                                                                                                                                                    |
| CE         | Central Europe                                                                      | https://www.entsoe.eu/bites/ccr-ce/about/                                                                                                                                                                                                                    |
| CSE        | Central Southern Europe                                                             | https://eepublicdownloads.entsoe.eu/clean-documents/tyndp-documents/TYNDP2018/rgip_CSE.pdf                                                                                                                                                                   |
| CGM        | Common Grid Model                                                                   | An output of the merging tool, which is a aggregation of all the individual networks                                                                                                                                                                         |
| DC         | Direct Current                                                                      |                                                                                                                                                                                                                                                              |
| DST        | Daylight Saving Time                                                                |                                                                                                                                                                                                                                                              |
| D2/2D      | 2 Days Ahead                                                                        | Can be seen in naming conventions, other possible values are listed [here](https://powsybl.readthedocs.io/projects/powsybl-core/en/latest/grid_exchange_formats/ucte/format_specification.html#file-name-convention)                                         |
| EIC        | Energy Identification Code                                                          | https://www.entsoe.eu/data/energy-identification-codes-eic/                                                                                                                                                                                                  |
| (G)LSK     | (Generator and) Load Shift Keys                                                     | Describes how a change in injection is distributed in the network (could be proportionnaly, an ordered list, ...) [Specification here](https://eepublicdownloads.entsoe.eu/clean-documents/CIM_documents/Grid_Model_CIM/GLSK_Profile_Specification_v2.1.pdf) |
| HVDC       | High Voltage Direct Current                                                         | Often located between borders; more details on [Wikipedia](https://en.wikipedia.org/wiki/High-voltage_direct_current)                                                                                                                                        |
| IGM        | Individual Grid Model                                                               | A network file covering only one area                                                                                                                                                                                                                        |
| NP(F)      | Net Position  (Forecast)                                                            | The sum of electricity exports and imports for a specific zone at a given time (in regard to another zone, here commonly CE)                                                                                                                                 |
| TSO        | Transmission System Operator                                                        | https://www.entsoe.eu/about/inside-entsoe/members/                                                                                                                                                                                                           |
| OLF        | OpenLoadFlow                                                                        | A library [Implemented by PowSyBl](https://github.com/powsybl/powsybl-open-loadflow), used to run [load flows ](https://powsybl.readthedocs.io/projects/powsybl-core/en/latest/simulation/loadflow/index.html)                                               |
| PST        | Phase Shifting Transformer                                                          | https://www.entsoe.eu/technopedia/techsheets/phase-shifting-transformers/                                                                                                                                                                                                                                                             |
| VH         | Virtual Hub                                                                         |  a virtual bidding zone without any buy and sell orders, used to represent the imports and exports on a border                                                                                                                                                                                                                                                            |
| QC         | Quality Check                                                                       |                                                                                                                                                                                                                                                              |
| UCTE(-DEF) | Union for the Co-ordination of Transmission of Electricity (- Data Exchange Format) | https://powsybl.readthedocs.io/projects/powsybl-core/en/latest/grid_exchange_formats/ucte/format_specification.html                                                                                                                                          |
